# Assets placeholder

Add these 3 files (1024×1024 PNG recommended):

- `icon.png` — App icon (navy #14213d background, white "أيوب")
- `splash.png` — Splash screen, centered logo on #14213d
- `adaptive-icon.png` — Android foreground (transparent bg, 1024×1024)
- `favicon.png` — Web favicon (optional)

Quick generate with any icon generator or use `expo` default then replace.
Expo will warn if missing but will still run with fallback.
